Third-party software included in HELINK for Android
====================================================

HELINK runs these programs as separate processes. Their source code is available
from the projects listed below.

yt-dlp (nightly 2026.10.10.233141 at build time, updated by the app)
  License: The Unlicense (public domain) - https://github.com/yt-dlp/yt-dlp
  The app downloads newer builds from https://github.com/yt-dlp/yt-dlp-nightly-builds
  and checks them against the published SHA-256 checksums.

yt-dlp-ejs 0.8.0 (bundled inside yt-dlp)
  License: The Unlicense - https://github.com/yt-dlp/ejs
  Bundles astring (MIT) and meriyah (ISC).

Python 3.12, FFmpeg 7.1 and QuickJS 2025-04-26 (Android builds)
  Built by the Termux project (https://github.com/termux/termux-packages) and packaged
  for Android apps by youtubedl-android 0.18.1 (https://github.com/yausername/youtubedl-android,
  GPL-3.0). The APK contains lib/<abi>/libpython.so, libffmpeg.so, libffprobe.so and
  libqjs.so; on first start the app downloads libpython.zip.so and libffmpeg.zip.so (the
  libraries) from that repository at commit d725d5c9a18c3a99a13ee0308bf78275dc310760 and
  checks them against SHA-256 sums.
  - Python: Python Software Foundation License - https://www.python.org/download/releases/3.12/license/
    (with OpenSSL (Apache-2.0), SQLite (public domain), zlib, libffi (MIT), expat (MIT),
    bzip2, xz/liblzma, ncurses, readline (GPL-3.0))
  - FFmpeg: GPL (built with x264, x265, Xvid, vid.stab, rubberband and other libraries,
    which makes the build GPL-3.0) - https://ffmpeg.org/legal.html
    Source: https://ffmpeg.org/download.html and the Termux build recipes linked above.
  - QuickJS: MIT License, Copyright (c) 2017-2025 Fabrice Bellard and Charlie Gordon -
    https://bellard.org/quickjs/

Kim_Vocal_2 (music removal; downloaded by the app the first time it is used)
  An MDX-Net voice model: the network by KUIELab (MIT, https://github.com/kuielab/mdx-net),
  trained by KimberleyJSN, as published by Ultimate Vocal Remover (MIT,
  https://github.com/Anjok07/ultimatevocalremovergui) on GitHub. The app downloads the
  ONNX file, checks it against a SHA-256 sum, and runs the network with its own program
  (lib/<abi>/libhelinksep.so, written for HELINK in Go, built from native/sep; no ONNX
  library is used). It is the same model and code HELINK for Windows uses.

The Go runtime and standard library (in libhelinksep.so)
  Copyright 2009 The Go Authors. BSD-3-Clause License - https://go.dev/LICENSE

Alexandria font
  Copyright 2022 The Alexandria Project Authors (https://github.com/Gue3bara/Alexandria)
  SIL Open Font License 1.1 - https://openfontlicense.org
